# 超级工厂 v2.0.1

[下载 Windows x64 运行包](https://github.com/JunyeFu/superfactory-releases/releases/download/v2.0.1/SuperFactory-2.0.1-Windows-x64.zip) · [下载示例工厂](https://github.com/JunyeFu/superfactory-releases/releases/download/v2.0.1/SuperFactory-2.0.1-Example-Factory.zip)

完整解压运行包后双击 `superfactory.exe`。需要 Windows 11 x64 和 WebView2，请保留同目录的模型、字体及设备运行时。详细步骤见包内《使用说明》。

## 开始使用

1. 从模板新建工程，选择“纸包装多产品工厂 · 92台设备”。
2. 点击“使用模板演示配置”，预览并创建工厂，选择方案后运行。
3. 在全厂、流水线及物品跟随视图查看结果；通过“文件”菜单保存和打开工程。
4. 如需查看已保存的真实产运记录，解压示例工厂包，打开其中的“纸箱产运演示”目录。点击“云端生产 → 执行”，选择“已保存记录1”，向下滚动，点击“回看执行画布与时间轴”。

查看示例历史无需云凭据；重新发起云端生产需要部署者签发的私有连接文件。公开包不含账户配置、令牌或数据库密码。

本地92设备流程的运行、成品跟随、保存和新进程重开，以及历史画布和运输筛选已验证。真实产运案例包含1件产出、3趟运输、15条已派命令及正常停止；93端点整厂全部订单、长时间性能及大历史归档仍待验。
